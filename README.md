# Abhishek Kumar — Cybersecurity Portfolio

A responsive, static HTML/CSS/JavaScript portfolio designed for GitHub Pages or Vercel. No build tools or dependencies are required.

## Run locally

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a new public repository on GitHub (for example, `abhishek-portfolio`).
2. Upload **all files and folders inside this project** to the repository root. Keep `index.html` at the root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment and open the URL GitHub shows you.

## Publish with Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Use the **Other** framework preset; leave build command and output directory empty/default for this static site.
4. Click Deploy.

## Before publishing

- Review your phone number and email before making the site public.
- Verify certificate names, issuers, dates, and internship details against the original documents.
- Replace any social/profile URL if it changes.
- This is a static site; the PDF documents are included under `assets/` and linked from the page.

No `.gitignore` file is included.
